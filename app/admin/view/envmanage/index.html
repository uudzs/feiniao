运行TTS服务：先确保根目录下有 tts_server.py 文件，并成功安装了 pip install edge-tts fastapi uvicorn 相关运行环境，最终成功运行了 nohup uvicorn tts_server:app --host 0.0.0.0 --port 25008 > tts_server.log 2>&1 & TTS服务。
此项需与 TTS 服务的 AUTH_ENABLED 保持一致；开启后由系统按现有令牌逻辑访问。

反向采集
数据表状态：{if $tables_installed}已初始化{else}未初始化 {/if}。开启反向采集前必须完成初始化。
必须与采集器 .env 中的 COLLECTOR_API_KEY 完全一致。
这是采集器访问小说系统的地址，如果采集器与本系统在同一台服务器，建议添加一个本地的请求端口，比如：127.0.0.1:25012，当然也可以写本系统用户可方问的地址。
用于验证回调签名，只配置在小说系统，由系统随任务安全传给采集器；建议使用至少 32 位随机字符串。
部署说明

同步采集器密钥：打开采集器目录 .env，将 COLLECTOR_API_KEY=新密钥 保存，然后重启采集器。回到本页填写同一个值并测试。密钥或采集器地址发生变化后，未测试通过将不能保存启用状态。

宝塔计划任务：进入“计划任务” → “添加任务” → 类型选“Shell 脚本” → 名称填写“反向采集调度” → 执行周期建议每分钟 → 脚本填写 cd /www/wwwroot/你的站点目录 && php think collect:dispatch。先在 SSH 中手工执行一次确认输出无错误，再启用计划任务。

实时体验：页面请求只负责快速创建任务，计划任务负责可靠补偿；现有章节缺失时的高优先级触发和前端轮询不会被本页设置阻塞。修改配置后，请重启正在常驻运行的 PHP/队列进程。

翻译服务配置当前只读且不在本页面修改，保存时会原样保留。
